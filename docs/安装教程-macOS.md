# 万象筛图 · Mac 安装教程（给客户的版本）

> 写给完全不懂电脑术语的用户，跟着图做即可，全程约 1 分钟。

## 第一步：下载正确的版本

先确认自己的电脑芯片：点屏幕**左上角苹果图标 → 关于本机**：

- 写着「芯片：Apple M1 / M2 / M3 / M4」→ 下载 **arm64** 那个文件
- 写着「处理器：Intel」→ 下载 **x64** 那个文件

文件后缀都是 `.dmg`。

> 💡 **省事小技巧**：如果用浏览器直接从 GitHub 下载，部分新系统会拦一道；把 dmg 文件放到**百度网盘/阿里云盘**再下载给客户（或自己从网盘转存下载），网盘客户端下载的文件不带拦截标记，多数情况能跳过第三步直接打开。

## 第二步：安装（拖一下就行）

1. 双击下载好的 `.dmg` 文件；
2. 会弹出一个小窗口，左边是软件图标，右边是 Applications（应用程序）文件夹；
3. **按住左边的图标，拖到右边的文件夹上，松手**——安装就完成了。

## 第三步：首次打开（分两种情况）

### 情况 A：双击能直接打开 🎉

恭喜，不用看下面了，直接用。

### 情况 B：提示"已损坏"或"无法打开，来自身份不明的开发者"

这是因为软件还没做苹果官方认证（不影响使用安全），只需放行一次：

1. 回到刚才那个 dmg 小窗口（没有就重新双击 dmg 打开）；
2. **双击窗口里的「打不开请双击我.command」**：
   - 如果弹出"无法验证开发者"：用**鼠标右键点它 → 选"打开" → 再点"打开"**（只有第一次需要右键）；
   - 会弹出一个黑色终端窗口，自动跑几行字，显示 **"✅ 修复完成"** 后，按回车关掉它；
3. 去「启动台」或「应用程序」文件夹里双击 **万象筛图**，就能正常打开了。

> 如果系统弹提示要求输入开机密码：输入后回车即可（输入时屏幕不显示字符，是正常的）。

### 还不行？（少数新系统的最后一步）

打开 **系统设置 → 隐私与安全性**，往下滚动，会看到一行"已阻止使用 万象筛图"，点旁边的 **"仍要打开"**，输入开机密码，然后回启动台正常双击即可。此后再也不用操作。

## 常见问题

**问：软件打开了，但右上角写着“基础引擎”或“降级”字样？**
答：说明内置 AI 引擎没被系统放行，人物分类和瑕疵检测不会工作。回 DMG 窗口**再双击一次「打不开请双击我.command」**（新版脚本会自动补签引擎），完成后完全退出软件重新打开，右上角变成“完整 12 维检测”即恢复正常，再用软件里的重新筛选跑一遍即可。

**问：那个 .command 文件是什么？会不会有病毒？**
答：是本软件自带的一小段"放行"脚本，作用只是告诉 macOS"这个软件我信任"。不放心可以查看它的内容，只有几行说明文字和一条命令。

**问：以后软件更新要怎么装？**
答：下载新的 dmg，重复第二、三步即可（直接拖进去覆盖旧版本，数据不会丢）。

**问：Windows 电脑怎么装？**
答：Windows 下载 Setup.exe，双击一路"下一步"即可，无任何特殊操作。
